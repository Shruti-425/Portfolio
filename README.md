- 3D visual elements and graphics
- Project and skills showcase
- Experience and achievements section
- Contact and social links
- Optimized production build

---

## 🛠️ Built With

### Frontend
- **React 19** — Component-based user interface
- **JavaScript (ES6+)** — Application logic
- **Vite** — Development and build tooling

### Styling & UI
- **Tailwind CSS** — Utility-first styling
- **CSS** — Custom styling and glassmorphism effects
- **Lucide React** — Icons

### Graphics & Animation
- **Three.js** — Interactive 3D elements
- **WebGL & Canvas API** — Graphics and visual effects
- **Framer Motion** — UI animations and transitions
- **Canvas Confetti** — Interactive visual effects

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shruti-425/Portfolio.git
```

### 2. Navigate to the project

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```
