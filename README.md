
## 🛠️ Tech Stack

- **Core**: React 19, JavaScript (ES6+), Vite
- **3D & Graphics**: Three.js, WebGL, Canvas API
- **Styling & UI**: Tailwind CSS, Vanilla CSS Glassmorphic design tokens
- **Animations & Icons**: Framer Motion, Lucide React, Canvas Confetti

## 💻 Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
